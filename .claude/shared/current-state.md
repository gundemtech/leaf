- **Sparkle ship gotchas**: (a) Xcode Debug LeafAgent залипает в launchd → `pkill -f "DerivedData.*LeafAgent"` pre-ship; (b) AX permission иногда требует toggle после bundle replace (CDHash меняется); (c) `CFBundleVersion` monotonic per ship; (d) dev-only: `/Applications/Leaf.app` ↔ DerivedData сбрасывает BTM disposition.
