# Термины проекта

Общий словарь — чтобы оба Claude Code и оба разработчика говорили одинаково.

| Термин | Значение |
|---|---|
| **LeafControl** | Название приложения (macOS, далее iOS) |
| **Второй мозг** | 4 Linear Docs в проекте `Leaf`: Session Log / Architecture Decisions / Conventions / Ideas & Principles |
| **Shared memory** | `.claude/shared/*.md` в репо — контекст, автоматически читаемый Claude Code обоих разработчиков |
| **Session Log** | Append-only журнал саммари сессий в Linear |
| **ADR** | Architecture Decision Record — запись в Linear Doc `Architecture Decisions` |

---

> Дополняется по мере появления доменных терминов (трекинг, события ввода, метрики и т.п.)
