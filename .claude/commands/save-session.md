# /save-session

Аргументы пользователя: $ARGUMENTS

---

## Режим 1 — аргументы ПУСТЫ (`/save-session` без текста)

Claude сам анализирует сессию и предлагает саммари.

**Шаги:**

1. Проанализируй ВСЮ текущую сессию: что обсуждали, что сделано, какие решения приняты, какие идеи/принципы прозвучали.
2. Сформируй черновик по шаблону:

   ```
   ## <YYYY-MM-DD HH:MM> — <автор (git config user.name или системный пользователь)>

   **Сделано:**
   - пункт 1
   - пункт 2

   **Решения (кандидаты в Architecture Decisions):**
   - решение 1

   **Идеи / принципы (кандидаты в Ideas & Principles):**
   - идея 1

   **Open questions:**
   - вопрос 1
   ```

3. Пустые разделы — пропускай, не оставляй заглушек.
4. Для каждого пункта из "Решения" и "Идеи / принципы" **явно спроси** пользователя: "Перенести в <Architecture Decisions | Ideas & Principles>?" — пользователь подтверждает y/n построчно или сразу "все / никакие".
5. После подтверждения через Linear MCP:
   - Основной блок целиком — append в Linear Doc **Session Log** (проект `Leaf`).
   - Подтверждённые "Решения" — append в Linear Doc **Architecture Decisions**.
   - Подтверждённые "Идеи / принципы" — append в Linear Doc **Ideas & Principles**.
6. В конце покажи ссылки на обновлённые доки.

---

## Режим 2 — аргументы НЕ пусты (`/save-session <текст>`)

Пользователь сам знает что сохранить — записываем дословно, без анализа.

**Шаги:**

1. Определи целевой doc:
   - Если аргументы начинаются с `--to=architecture` → Linear Doc **Architecture Decisions**
   - `--to=conventions` → Linear Doc **Conventions**
   - `--to=ideas` → Linear Doc **Ideas & Principles**
   - Без флага → Linear Doc **Session Log** (по умолчанию)
2. Сохрани текст как есть, с префиксом-заголовком `## <YYYY-MM-DD HH:MM> — <автор>`.
3. НЕ анализируй сессию, НЕ додумывай, НЕ спрашивай подтверждения.
4. Покажи ссылку на обновлённый doc.

---

## Технические детали

- Linear MCP должен быть подключён в текущем Claude Code.
- Проект в Linear: `Leaf`. Docs: `Session Log`, `Architecture Decisions`, `Conventions`, `Ideas & Principles`.
- Время — локальное (не UTC). Автор — из `git config user.name`, fallback на системного пользователя.

## Fallback при недоступном Linear MCP

1. Сообщи пользователю: "Linear MCP недоступен, сохраняю черновик локально."
2. Запиши черновик в `.claude/shared/drafts/<YYYY-MM-DD-HHMM>-<slug>.md`.
3. Напомни: после восстановления MCP — `/save-session --flush-drafts` (команду отдельно реализуем позже).

## Чего НЕ делать

- Не писать в Linear без подтверждения (кроме Режима 2, где пользователь сам задал текст).
- Не дублировать одну и ту же запись при повторном вызове команды.
- Не тянуть сырой транскрипт сессии — только выжимку.
- Не пушить в git — это отдельная операция.
