# /pull

Быстрый `git pull` в локальном клоне `~/Desktop/Leaf/leaf-docs`, чтобы подтянуть свежие изменения whitepaper от партнёра перед началом новой задачи.

## Алгоритм

1. Выполни:
   ```bash
   cd ~/Desktop/Leaf/leaf-docs && git pull --ff-only
   ```
2. Разбери вывод и отчитайся коротко:
   - **"Already up to date"** → "leaf-docs уже актуален".
   - **Fast-forwarded N commits** → покажи последние 3 коммита (`git log -3 --oneline`) и кратко скажи что изменилось на уровне файлов (`git diff --stat HEAD~N`). Не пересказывай контент полностью — только "в каких разделах whitepaper были правки".
   - **Non-fast-forward / conflict / diverged** → остановись, покажи статус юзеру, попроси указать как разруливать. Не делай merge / rebase / reset сам.
   - **Ошибка сети / auth** → покажи stderr, предложи проверить GitHub credentials.

## Когда запускать

- В начале сессии если давно не работал.
- Перед любой содержательной задачей по архитектуре / продукту / whitepaper.
- Когда кажется что юзер или партнёр мог обновить whitepaper, пока ты не смотрел.

## Чего НЕ делать

- Не пушить ничего из этого шага — только pull.
- Не трогать другие репо (`leaf`, `leaf-relay`).
- Не делать `git reset --hard` даже если pull падает — это потенциальная потеря локальных правок.
