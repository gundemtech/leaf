# Validation Approach

## Kill criteria

| Stage | Criterion | If unmet |
|-------|-----------|----------|
| End of Sprint 1 | Both founders use Leaf every day | Solo-wedge isn't working |
| End of Sprint 2 | We share memory with each other and feel real value | Team hypothesis is wrong |
| One month post-launch | 5+ paying teams | Pricing / positioning isn't working |
| At any time | Cursor / Anthropic ship E2E team memory | Urgent re-assessment |
