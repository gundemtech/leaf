# Architecture Decision Records

This directory holds ADRs for Leaf — short, immutable records of architectural decisions and the context that produced them.

Format: Status · Context · Decision · Consequences.

ADRs 001–010 exist as historical labels referenced in code and shared memory; the canonical decision log for those lives in the public whitepaper at [leaf-docs.gundem.tech](https://leaf-docs.gundem.tech). ADRs 011–017 (this update) are written here directly because they accompany the v4 strategy refresh and should travel with the code.
